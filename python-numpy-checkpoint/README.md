# Loan Prediction Data Analysis

This project contains a Python script (`index.py`) that uses the `numpy` library to perform a basic statistical analysis on a loan prediction dataset.

## `index.py`

The script performs the following steps:

1.  **Load Data**: It loads data from `Loan_prediction_dataset.csv`.
2.  **Extract Loan Amount**: It extracts the column containing loan amount data.
3.  **Clean Data**: It handles missing values in the loan amount column by filtering them out.
4.  **Calculate Statistics**: It calculates the following statistical measures for the loan amounts:
    - Mean
    - Median
    - Standard Deviation
5.  **Output**: The script then prints these calculated values to the console.

### Dependencies

- `numpy`
