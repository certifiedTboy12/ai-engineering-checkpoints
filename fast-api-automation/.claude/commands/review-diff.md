# Review Diff

Review the current git diff.

Do not modify files.

Check:

1. Whether the changes match the requested feature.
2. Whether unrelated files were modified.
3. Whether tests were added or updated appropriately.
4. Whether the implementation follows CLAUDE.md.
5. Whether the tests directory rules were followed.
6. Whether security-sensitive information was introduced.
7. Whether the diff is unnecessarily large.

Return:

- Findings
- Potential problems
- Missing tests
- Security concerns
- Overall review summary

Do not edit files.
