# Plan Feature

Create an implementation plan for the requested feature.

Do not modify files.

The plan must contain:

## Goal

Describe the requested behavior.

## Expected Files

List every file that may need to be created or modified.

## Implementation

Describe the smallest reasonable implementation.

## Tests

List the tests that should be added or modified.

## Risks

Identify possible regressions, compatibility concerns, or security issues.

## Verification

List the commands that should be run after implementation.

Do not edit files until the user explicitly approves the plan.
