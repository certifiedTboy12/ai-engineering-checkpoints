# Portfolio Case Study

## Project Summary

The Home Services Management Platform is a full-stack web application designed to make home-service requests easier to submit, schedule, manage, and track.

## Problem

Customers can struggle to understand service options, submit complete requests, and track what happens after a request is created. Service teams also need structured data and status workflows to manage requests consistently.

## Target User

The product is designed primarily for customers requesting home services and service teams responsible for managing those requests.

## Solution

I built a centralized service-management experience that connects a responsive React frontend with a REST API and persistent database. The interface guides the customer from service selection to request submission and provides service-status visibility after submission.

## Key Features

- Service catalogue
- Service details
- Request form
- Scheduling
- Service status tracking
- Dashboard
- Upcoming service
- Recurring plans
- Customer communication
- Completion/checklist workflow
- API integration
- Validation and automated testing

## My Role

I designed and implemented the application experience, including frontend components, responsive layouts, routing, service-request interactions, dashboard concepts, API integration, validation, testing strategy, and technical documentation.

## Challenges

The main challenge was turning a collection of service screens into one coherent workflow. The application needed to represent real service states, schedules, recurring plans, customer communication, and backend persistence while remaining simple for customers to understand.
