# LinkedIn Project Post

I recently completed a capstone project: a **Home Services Management Platform** designed to make it easier for customers to request, schedule, and track home services.

The application includes service discovery, request forms, scheduling, service-status tracking, recurring plans, an upcoming-service view, and a management dashboard.

### Technologies used

- React and JavaScript
- Tailwind CSS
- Wouter
- Framer Motion
- Node.js and Express
- MongoDB
- Jest and Supertest
- Docker and CI/CD

One of the biggest lessons from the project was that building a useful application is more than creating individual screens. I had to think about the complete workflow: how a request is created, validated, stored, updated, and communicated back to the user.

I also learned more about API testing, application architecture, environment-variable security, release checklists, and documenting a project for other developers.

The next iteration would focus on stronger role-based access control, payments, real-time notifications, provider assignment, and end-to-end testing.
