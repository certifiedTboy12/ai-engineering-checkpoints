# Python Class Calculator

This is a simple command-line calculator built in Python using an object-oriented approach. It features basic arithmetic operations and can be easily extended with more advanced mathematical functions.

## Features

- **Basic Arithmetic Operations**: Addition (`+`), Subtraction (`-`), Multiplication (`*`), Division (`/`).
- **Advanced Operations**:
  - Exponentiation (`^`)
  - Square Root (`sqrt`)
  - Natural Logarithm (`log`)
- **Extensible Design**: New operations can be added to the calculator easily.
- **Robust Error Handling**: Catches common errors such as invalid input, division by zero, and mathematical domain errors (e.g., square root of a negative number, logarithm of non-positive numbers).
- **User-Friendly Interface**: Simple command-line interaction.

## How to Run

1.  **Save the code**: Ensure the `index.py` file is saved on your local machine.
2.  **Open a terminal or command prompt**: Navigate to the directory where you saved `index.py`.
3.  **Run the script**: Execute the script using Python:

    ```bash
    python index.py
    ```

## Usage

Upon running the script, you will be presented with a list of available operations. You will then be prompted to enter an operation, followed by the required numbers.

### Examples

**Addition:**

```
Enter an operation: +
Enter the first number: 10
Enter the second number: 5
Result: 15.0
```

**Square Root:**

```
Enter an operation: sqrt
Enter a number: 25
Result: 5.0
```

**Quit:**

```
Enter an operation: q
Thank you for using the calculator!
```
